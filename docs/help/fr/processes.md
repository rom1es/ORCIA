## À quoi sert cet écran

Cet écran permet de consulter, lancer et concevoir vos processus métiers gouvernés. Vous pouvez choisir entre un pilotage par jalons (étapes ordonnées avec contrôles qualité) et un pilotage par objectif adaptatif, tout en gardant la main sur les validations humaines.

## En 3 gestes

1. Parcourez les processus disponibles sur votre Espace et repérez leur mode (Piloté par les jalons ou Piloté par l'objectif).
2. Cliquez sur « Ouvrir le Studio » pour ajuster les instructions, les agents autorisés et les points de validation, puis enregistrez votre brouillon.
3. Lancez une exécution ou ouvrez la carte de chaîne de valeur pour identifier les goulots d'étranglement entre étapes humaines et automatisées.

## Un exemple réel

Claire ouvre le processus « Qualification de demande & Note de cadrage », bascule la fiche en mode Objectif adaptatif, autorise l'agent Orchestrateur Produit, puis enregistre et publie la nouvelle version pour toute son équipe.

## Ce qui coince souvent

- **Un processus reste à l'état de brouillon** : cliquez sur « Publier » dans le Studio pour le rendre sélectionnable lors d'un lancement depuis le Cockpit.
- **Le Studio recommande un écran d'ordinateur sur mobile** : vous pouvez consulter ou ajuster les champs essentiels sur téléphone, mais la conception multi-blocs complète est optimisée pour un poste de bureau.
- **Une étape est en attente d'approbation** : ouvrez le tiroir d'exécution ou rendez-vous dans le Cockpit pour valider, amender ou renvoyer vers une étape précédente.
