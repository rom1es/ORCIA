## 2. Detailed Active Architectural & Governance Decisions

### `D1` + `R2` + `R3` — Unified Turn Engine, "Deepen" Flow & Mode B Deferral
- **Context:** Unify three divergent paths (`/three-speed/stream`, unused 5-node DAG `AssistantAgentService`, and parallel `POST /executions/reflexive` calls in `useInboxPanelController`) while guaranteeing Speed 1 `TTFT p95 < 1.2 s`, `AD-3` human anchors, and V5 SI write lock (`H-01`, `H-02`, `H-29`).
- **Effective rule:**
  - `AssistantTurnEngine` (`packages/orcia-core`) runs Speed 1 via a single-shot fast-path (bounded `< 50 ms` RAG pre-fetch, direct streaming, session persisted post-first-byte) and Speed 2/3 via the `ASSISTANT` profile of `NonDeterministicReflexiveRuntime`.
  - Historical `AD-15` 5 nodes become fixed phases `N1 IntentGuard → N2 Planner & Ontology → N3 Pre-fetch / Tool Loop → N4 Server EvidenceTable → N5 Synthesis (AssistantPromptBuilder) → CitationGuard`.
  - No automatic Speed 1 → Speed 2 escalation: `turn_completed` carries deterministic `low_evidence` (empty `EvidenceTable`), and the UI displays a **"Deepen"** button (when `supports_tools=true`) that starts a linked Speed 2 turn (`parent_turn_id`).
  - Graphical Mode B Studio is deferred (`ACTION_ITEM-26.1`); only Mode A 3-level text instructions remain active. `ConnectorReflexiveWriteGateAdapter` is forbidden in the `ASSISTANT` profile.
- **Rejected alternatives:** 100% `NonDeterministicReflexiveRuntime` for Speed 1 (pre-first-byte PG18 write threatens `< 1.2 s` TTFT); rewriting the sync 5-node DAG; heuristic pre-LLM auto-escalation; free-form Mode B graph editing.

### `D2` + `R1` — Async Protocol (`202` + Redis Streams) & Single `apps/api` Hosting
- **Context:** Eliminate `ACTIVE_WORKSPACE_TURNS` RAM state, multi-tab collisions, F5 drops, and `--workers > 1` incompatibility (`H-10`, `H-21`), without adding Dramatiq operational complexity since pod-crash survival for long turns is not required.
- **Effective rule:** `POST /assistant/turns` validates guards and returns `202` + `turn_id`; `GET /assistant/turns/{turn_id}/stream?after=<cursor>` replays/streams Redis Streams across workers. All turns run in bounded `asyncio.Task` inside `apps/api` (`add_done_callback`, `SIGTERM` graceful drain capped by profile wall-clock budget). A Redis liveness key (`TTL` refreshed while active) flags crashed turns on reattach with `stream_error` `ERR_ASSISTANT_TURN_INTERRUPTED` (RFC 9457, no auto-retry).
- **Rejected alternatives:** Dramatiq worker execution for Speed 2/3 + heartbeat `503` (over-engineered once crash survival was dropped); module-level in-memory turn dicts.

### `D3` + `R8` — Env-Var SSRF Allowlist, DNS Pinning & Day-0 Setup State
- **Context:** Close DNS-rebinding SSRF gaps (`H-16`) and unauthenticated Day-0 config exposure (`H-17`) while preserving on-prem Ollama/vLLM support and `12-factor` OpenShift alignment (`AD-23`).
- **Effective rule:** Private/on-prem hosts (RFC 1918, `.local`, `.internal`) are governed by ops env var `ORCIA_LLM_ALLOWED_PRIVATE_HOSTS` (`localhost` permitted only when `ORCIA_ENV in ("local", "test")`); DB/UI allowlist is deferred (`ACTION_ITEM-26.5`). Cloud metadata/link-local ranges (`169.254.0.0/16`, `fe80::/10`, `100.100.100.200`, `metadata.google.internal`) and internal ORCIA ports (`5432`, `6379`, S3) are permanently blocked. Validation runs on save and connection with `getaddrinfo` DNS pinning. `GET /bootstrap/platform-setup-state` unauthenticated response returns only `{is_initialized, step}`; `apiKey` never enters `platform_setup_snapshot`; `str(exc)` passes through the secret scrubber.

### `D4` — Thread Messages & Tool Trace Separation
- **Effective rule:** New PG18 table `assistant_thread_messages` (`UUIDv7` PK, `role CHECK IN ('user', 'assistant')`, `citation_map JSONB`, `token_count`, `created_at`) replaces `localStorage` history and `" | "` splitting of `thread_summary`. Tool execution traces remain in `reflexive_execution_sessions` keyed by `turn_id` and are never injected as `role: "tool"` history messages (`H-15`, `H-18`).

### `D5` + `R7` — Three Text Streaming Adapters + Two Native Tool-Calling Dialects
- **Context:** `LLMPort` (`kernel/ports.py:L75-85`) has no tool-calling interface.
- **Effective rule:** Keep all 3 `httpx` text/reasoning streaming adapters (OpenAI-compatible, Anthropic, native Gemini `CAP-076`). Implement native `tool_calls` parsing/re-injection in `26.6a` strictly for **OpenAI-compatible** (covers OpenAI, vLLM, Ollama `/v1`, Azure) and **Anthropic**. Native Gemini REST and non-`/v1` Ollama default to `supports_tools=false` (`422 ERR_MODEL_TOOLS_UNSUPPORTED` on Speed 2/3, UI disabled, zero ReAct/XML emulation; `ACTION_ITEM-26.4` tracks future native parsers).

### `D6` + `R4` — `CONTINUE_IN_PROCESS` via DBOS & Direct Cutover Without Facade
- **Effective rule:** `POST /turns/{id}/approve` and `POST /folders/{id}/launch-process` instantiate durable DBOS + PG18 workflows (`AD-2`) halting at `WAITING_FOR_HUMAN_ANCHOR` (`AD-3`, `H-05`). Because `apps/web` is the sole consumer, `26.7` performs an atomic cutover (backend + UI turn transport + E2E specs `02/12/16/21`) and deletes obsolete routes immediately in the story that replaces them (`26.4b` Mode B, `26.7` `/three-speed/*` + `/chat*` + `/verify-turn` + `/artifacts/action`, `26.8` `/save-and-launch`, `26.9` duplicate `POST /threads/{id}/turns`). `/three-speed/*` compatibility facade is deferred to `ACTION_ITEM-26.2`.

### `D7` & `D9` — MCP `assistant.ask` & Honest `capabilities.yaml`
- **Effective rule:** Wire `assistant.ask` (`POST /mcp/spaces/{ws}/invoke`) in `26.7` to Speed 1 read-only governed mode (`D7`). Downgrade `CAP-022`, `CAP-070`, `CAP-072` to `verification: api` in `26.1`, register `CAP-260` (`api`) in `26.6b`, and promote all 4 to `runtime` only in `26.10` after E2E `spec 22` passes (`D9`).

### `R5` & `R6` — Storage & Measure-First Simplifications
- **Effective rule (`R5`):** Omit `assistant_citation_drafts` entirely (its sole caller `/artifacts/action` is deleted in `26.7`, avoiding an orphan SQL adapter). Delete `_saved_drafts` and `execute_artifact_card_action` in `26.7` (leaving E2E `21` intact until `26.7`). Route phantom citation logs to `audit_ledger` (`ASSISTANT_PHANTOM_CITATION_PURGED`) and keep `assistant_turn_feedback` upsert table in PG18.
- **Effective rule (`R6`):** Omit Redis prompt caching and Outbox cache invalidation in `26.4a`; delete `InMemoryPromptCacheStore` and forged `outbox_event_id`. Benchmark prompt-assembly latency (`26.5`) and Speed 1 TTFT (`26.7`); only restore a cache via `ACTION_ITEM-26.3` if assembly p95 `> 50 ms`.

### `R9` — Sequential Lot 3 & Risk-Tiered Worker Routing
- **Effective rule:** Execute `26.3 → 26.4a → 26.4b` sequentially on `workspace: "inherit"` (no `share` worktrees or Alembic merge rechaining). Assign 2 distinct `flash` dev workers (Impl + Independent Verification) + `pro` review to high-risk stories (`26.1`, `26.6b`, `26.7`); assign 1 `flash` dev worker to standard dev stories (`26.2`, `26.3`, `26.4a`, `26.4b`, `26.5`, `26.6a`, `26.8`, `26.9`, `26.10`), with `pro` architecture/closure gates on `26.0` and `26.10` (plus `pro` escalation on 2 consecutive `flash` failures).
