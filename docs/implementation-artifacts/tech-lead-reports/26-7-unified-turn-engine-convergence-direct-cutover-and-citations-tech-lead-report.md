## 1. Need Analysis & Tech Lead Impact Study (Analyse du Besoin)

### 1.1 Context & Problem Statement
- **Observed split execution (`H-01`, `H-02`):**
  1. `useInboxPanelController.ts` triggers `streaming.sendTurn(...)` (calling `POST /api/v1/assistant/three-speed/stream`) **and** simultaneously fires `reflexive.startExecution(...)` (`POST /api/v1/executions/reflexive`) in deep/`@agent` mode, causing two parallel LLM executions, redundant spend, and split state.
  2. Three divergent backend surfaces exist (`/api/v1/assistant/three-speed/*`, `/api/v1/assistant/chat*`, and `/api/v1/assistant/turns*`), while `AssistantAgentService` maintains an unused 5-node DAG and `assistant_workspace_citations.py` exposes client-driven `/citations/verify-turn` and RAM-backed `/artifacts/action` (`_saved_drafts`, `H-09`).
  3. Server-side citation verification (`AssistantCitationAndV5GuardService.verify_and_sanitize_citations_async`) is not executed inline before `turn_completed` (`H-14`), nor is `citation_map` emitted as a first-class SSE v2 frame.
  4. `reflexive_execution_sessions` lacks an `execution_profile` column (`PROCESS` vs `ASSISTANT`), and MCP `assistant.ask` (`POST /api/v1/mcp/spaces/{ws}/invoke`, `D7`) currently falls back to synthetic template responses rather than invoking `AssistantTurnEngine` Speed 1 read-only governed mode.
- **Expected behavior (`AD-25`, `D1`, `D7`, `D8`, `R1`–`R6`):**
  - Single `AssistantTurnEngine` in `packages/orcia-core` handling Speed 1 (single-shot fast-path, `TTFT p95 < 1.2 s`, prompt-assembly `p95 <= 100 ms` / target `< 50 ms` without prompt cache per `R6`, `low_evidence: bool`, `supports_tools: bool`, `parent_turn_id` for linked Speed 2 "Deepen" turns) and Speed 2/3 (`NonDeterministicReflexiveRuntime` with `execution_profile='ASSISTANT'`, `write_gate=None`, `GovernedAssistantToolRouter`, and `synthesize-now`).
  - Server-side `CitationGuard` runs strictly before `turn_completed`, strips phantom `[Sn]`/`[Gn]`/`[On]` tags, updates persisted `assistant_thread_messages`, logs `ASSISTANT_PHANTOM_CITATION_PURGED` to `audit_ledger`, and emits `citation_map` SSE.
  - Canonical `assistant_turns.py` router exposes `/api/v1/assistant/turns*` (`POST /turns`, `GET /turns/active`, `GET /turns/{turn_id}/stream?after=`, `POST /turns/{turn_id}/stop`, `POST /turns/{turn_id}/approve`, `POST /turns/{turn_id}/synthesize-now`, `POST /turns/{turn_id}/feedback`), while legacy `/three-speed/*`, `/chat`, `/chat/stream`, `/citations/verify-turn`, and `/artifacts/action` (`_saved_drafts`, `execute_artifact_card_action`) are deleted directly (`R4`, `R5`).
  - `POST /api/v1/assistant/workflows/save-and-launch` (Story `26.8`) and duplicate `POST /api/v1/assistant/threads/{id}/turns` (Story `26.9`) remain untouched in their current files to preserve Story `26.8`/`26.9` boundaries.
