## 2. Detailed Findings by Question

### Question 1: Security & Attack Surface (2025–2026) — Next.js Node Server vs. Static Vite SPA + FastAPI
* **Next.js App Router Systemic Attack Surface:** Running `next start` (or `node server.js` in standalone mode) exposes a live Node.js HTTP server that parses internal routing headers, RSC Flight payloads, and Middleware subrequests `[D3-C1, D3-C2, D3-C4]`.
* **Critical CVEs in 2024–2026:**
  * **Middleware Auth Bypass (`CVE-2025-29927`, CVSS 9.1, March 2025):** Attackers sending a crafted `x-middleware-subrequest` header bypassed `middleware.ts` authentication/authorization checks completely `[D3-C1]`.
  * **Unauthenticated RCE in RSC Flight Protocol (`CVE-2025-55182` / "React2Shell", CVSS 10.0, December 2025):** Flaws in how `react-server-dom-*` deserialized RSC/Server Function payloads allowed unauthenticated remote code execution on Next.js 15.x and 16.x servers **even if the application defined zero custom Server Actions** `[D3-C2]`.
  * **Server Actions & Rewrites SSRF and DoS (`CVE-2024-34351` CVSS 7.5; `CVE-2026-23870` DoS; `CVE-2026-64645` & `CVE-2026-64649` SSRF; `CVE-2026-64642` Proxy Bypass):** Recurring server-tier patches required throughout 2024–2026 `[D3-C3, D3-C4]`.
* **Contrast with Static Vite SPA + FastAPI Backend:** Serving static `.html`, `.js`, and `.css` artifacts via hardened `nginx:alpine` or Caddy eliminates the Node.js runtime, RSC Flight parser, Server Action endpoints, and JS middleware attack surface completely `[D3-C5]`.

### Question 2: Self-Hosting Operations & Cost (Docker / Kubernetes)
* **Resource Footprint:** A **Vite + Nginx Static SPA** image is **20 MB–50 MB** on disk with **5 MB–15 MB** idle RAM (`30 MB–50 MB` K8s pod limit), whereas **Next.js Standalone** is **150 MB–300 MB** on disk with **60 MB–120 MB** baseline Node.js idle RAM (`256 MB–512 MB` K8s pod limit) `[D3-C6]`.
* **Horizontal Scaling:** Next.js 15/16 requires custom Redis `cacheHandler` / `cacheHandlers` and `cacheMaxMemorySize: 0` across replicas, whereas a static Vite SPA is 100% stateless `[D3-C7]`.

### Question 3: Ecosystem Vitality & Migration Reality (2025–2026)
* **Adoption Trajectory:** `@tanstack/react-router` and `@tanstack/react-start` reached ~12M–16M+ weekly npm downloads by October 2026 (`TanStack Start v1.0` GA on 2026-10-13) `[D3-C8]`.
* **Migration Reality:** Replacing `next/navigation` and thin `app/*/page.tsx` wrappers with `@tanstack/react-router` yields faster HMR/builds, compile-time URL search-param safety, and zero Node.js server maintenance `[D3-C9]`.
