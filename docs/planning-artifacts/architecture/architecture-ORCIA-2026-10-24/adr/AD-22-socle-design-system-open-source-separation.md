# AD-22 — Socle Design System Open Source `@orcia/ui` (`Radix UI Primitives` + Architecture `shadcn/ui`), Séparation Stricte Look & Feel (`tokens.css`) / Logique (`apps/web`) / Contenus (`i18n`), Conformité RGAA 4.1 & Hiérarchie Chromatique des Onglets [ADOPTED]

> Verbatim detail moved from `ARCHITECTURE-SPINE.md` on 2026-11-27 (baseline `bf44884`). The condensed binding form lives in the spine; this file is the full rationale.

- **Binds:** `all`
- **Prevents:** Duplication artisanale de la logique d'accessibilité clavier/ARIA (focus trap, *roving tabindex*, `aria-controls`, `Escape`) dans chaque écran ; couplage entre l'apparence visuelle (Look & Feel) et la logique métier ou les textes ; utilisation de couleurs hexadécimales en dur hors du Design System ; onglets inactifs à fond blanc se confondant avec les cartes de contenu ; déclenchement intempestif des gestionnaires de mots de passe (LastPass / 1Password / Bitwarden) sur les champs de configuration ou de clés d'API hors `/login`.
- **Rule:**
  1. **Encapsulation Exclusive dans `packages/ui` (`@orcia/ui`) sur Socle `Radix UI Primitives` + `shadcn/ui` (`ACTION_ITEM UX-DS-RADIX-01`)** : Les composants d'interface d'ORCIA reposent sur l'architecture open source **`shadcn/ui` + `@radix-ui/react-*`** (`Tabs`, `Dialog`, `AlertDialog`, `Select`, `DropdownMenu`, `Tooltip`, `Switch`, `Popover`), intégralement encapsulée dans `packages/ui/src/primitives/` (`DesignSystemControls.tsx`). `apps/web` n'importe jamais `@radix-ui/*` directement et consomme uniquement les primitives exposées par `@orcia/ui`.
  2. **Séparation Tripartite Stricte (Look & Feel vs Logique vs Contenus)** :
     - **Look & Feel (`packages/ui/src/styles/tokens.css` & classes `.orcia-ds-*`)** : Source unique de vérité pour 100 % des variables CSS (`--color-*`, `--radius-*`, `--font-*`, `--shadow-*`) et des classes de composants (`.orcia-ds-btn`, `.orcia-ds-tab`, `.orcia-ds-input`, `.orcia-ds-select`, `.orcia-ds-textarea`, `.orcia-ds-card`, `.orcia-ds-alert`). Aucune couleur hexadécimale (`#...`) n'est autorisée hors de `tokens.css`, et le Violet `#6D28D9` (`--color-human-led-violet`) reste exclusivement réservé à `HumanLedAnchorCard` (`human_authored_required: true`).
     - **Logique & État (`apps/web`)** : Routage TanStack Router v1, stores et appels `@orcia/api-client` (interdits dans `packages/ui`).
     - **Contenus (`apps/web/src/i18n/locales/{fr,en}.ts`)** : Textes bilingues injectés par props typées dans `@orcia/ui`, sans jargon technique d'implémentation dans les vues métier et avec renvoi systématique des explications vers la colonne d'aide contextuelle droite via `<ContextualInfoTriggerButton />` (`ⓘ`).
  3. **Hiérarchie Chromatique Unifiée des Onglets (`.orcia-ds-tab` / `[role="tab"]`)** : Sur l'ensemble des écrans d'ORCIA, tout onglet sélectionné ou ayant le focus (`aria-selected="true"` ou `:focus-visible`) affiche un **fond bleu intense** (`--color-tab-active-bg: #2563EB`, texte blanc `#FFFFFF`, bordure `#1D4ED8`, contraste WCAG AA `5.17:1`), tandis que tout onglet non sélectionné (`aria-selected="false"`) affiche un **fond bleu pâle** (`--color-tab-inactive-bg: #DBEAFE`, survol `#BFDBFE`, texte bleu foncé `#1E3A8A`, bordure `#93C5FD`, contraste WCAG AAA `8.95:1`).
  4. **Exhaustivité RGAA 4.1 & Parade Anti-Gestionnaires de Mots de Passe Hors `/login`** : Toutes les modales respectent `role="dialog"`, `aria-modal="true"`, sortie `<Échap>` / `Annuler` avec garde `useUnsavedChangesDialogGuard` (`isDirty`) et validation `<Entrée>`. Tous les champs de saisie et de secrets hors `/login` (`BiModeLoginView.tsx`) appliquent nativement `autoComplete="off"`, `data-lpignore="true"`, `data-1p-ignore="true"`, `data-bwignore="true"`, `data-form-type="other"` et le masquage CSS `.orcia-masked-secret-input` (`-webkit-text-security: disc`).
