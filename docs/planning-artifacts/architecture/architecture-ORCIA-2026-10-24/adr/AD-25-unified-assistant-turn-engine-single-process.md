# AD-25 — Unified Assistant Turn Engine, Single-Process Redis Turn Streaming, Fixed N1–N5 Constitutional Phases & Governed Tool Loop [ADOPTED]

> Verbatim detail moved from `ARCHITECTURE-SPINE.md` on 2026-11-27 (baseline `bf44884`). The condensed binding form lives in the spine; this file is the full rationale.

- **Binds:** `FR-1`, `FR-2`, `FR-3`, `FR-4`, `FR-5`, `FR-15`, `FR-23`, `FR-24`, `FR-26`, `FR-27`, `FR-33` (`CAP-022`, `CAP-069..076`, `CAP-260`)
- **Prevents:** Divergent assistant execution paths bypassing `AssistantHarness`, hybrid RAG, server citations, and `AD-3` human anchors; double LLM execution in `deep`/`@agent` mode; mocked or broken tool-calling loops; direct SI writes via connectors outside DBOS Gates; mid-SSE crashes from post-header observer/scope checks; cross-workspace IDOR via slug/UUID gaps; client-supplied source authorization lists; Layer 1 prompt injection or override; RAM-only turn/governance/feedback/lock state failing on `F5` reload or `--workers > 1`; and speculative Redis prompt caching before measuring SQL assembly latency.
- **Rule:**
  1. **Hybrid `AssistantTurnEngine` (`packages/orcia-core`) & "Deepen" Flow (`D1`, `R3`):** All assistant turns route through a single `AssistantTurnEngine` executing two paths over the unified `N1–N5` pipeline:
     - **Speed 1 (Single-Shot Fast-Path):** Bounded `< 50 ms` hybrid RAG pre-fetch (respecting `AD-24.6` optional embedding decoupling when `0` `embedding` model is active), direct SSE streaming, and post-first-byte PostgreSQL 18 session persistence to guarantee `TTFT p95 < 1.2 s`. Speed 1 performs zero pre-LLM auto-escalation and emits a deterministic `low_evidence: bool` flag on `turn_completed` when the server `EvidenceTable` is empty. After Speed 1 completes, the UI offers a **"Deepen"** button (rendered when `supports_tools=true`, visually highlighted when `low_evidence=true`) that launches a linked Speed 2 turn referencing `parent_turn_id`.
     - **Speed 2 / Speed 3 (`ASSISTANT` Profile of `NonDeterministicReflexiveRuntime`):** Executes bounded multi-step tool loops, budgets, `cancel`, and `synthesize_now` on the `ASSISTANT` profile of `NonDeterministicReflexiveRuntime`, leaving the `PROCESS` profile default behavior and `test_story_16_2_*` contracts completely untouched.
  2. **Single-Process `apps/api` Hosting & Redis Streams Reattachment (`D2`, `R1`):** All turn speeds (`1`, `2`, `3`) execute inside `apps/api` in bounded, tracked `asyncio.Task` handles (`add_done_callback`) with `SIGTERM` graceful drain capped by the profile wall-clock budget; **no Dramatiq worker** is used for assistant turns. Redis stores the `(workspace_id, user_id, turn_id)` active turn registry, the cursor-reattachable Redis Streams event buffer (`GET /api/v1/assistant/turns/<turn_id>/stream?after=<cursor>` supporting `F5` reload and multi-worker reattachment), `stop` cancellation signals, thread turn locks (`SET lock:thread:<thread_id> NX EX ...`), sliding-window rate-limiting & per-user concurrency semaphores, and a refreshed task liveness key (`TTL`). If an `apps/api` pod crashes mid-turn, liveness expiration detects the orphaned turn on reattach and emits terminal `stream_error` `ERR_ASSISTANT_TURN_INTERRUPTED` (RFC 9457 Problem Details + W3C `trace_id`, no automatic retry).
  3. **Fixed `N1–N5` Constitutional Phases & Sealed Guards (`D1`, `R2`):** Every turn executes the fixed phase topology `N1 IntentGuard -> N2 Planner & Ontology -> N3 Pre-fetch / Tool Loop -> N4 Server EvidenceTable -> N5 Synthesis (unified localized AssistantPromptBuilder) -> CitationGuard`. Constitutional guards (`Layer 1`, `N1`, `V5`, and `CitationGuard`) are sealed in code and strictly non-overridable. Graphical Mode B Studio editing is deferred (`ACTION_ITEM-26.1`); only Mode A 3-level declarative text instructions (`TEAM -> WORKSPACE -> USER` in `workspace_customization_overrides`) feed `AssistantPromptBuilder`.
  4. **Pre-Stream Security & Server-Side Context Assembly (`H-06..H-08`, `H-15`):** Every mutating `/api/v1/assistant/*` endpoint enforces `ScopeAccessGuard` (resolving both workspace UUIDs and slugs via `evaluator`) and `READ_ONLY_OBSERVER` checks (`HTTP 403 ERR_OBSERVER_MODE_READ_ONLY`) as FastAPI dependencies **before** HTTP `200` headers or any SSE byte. `READ_SOURCE` permissions and `CONFIDENTIAL_RESTRICTED` masking are enforced strictly server-side (`PermissionBrokerService` / `evaluator`, zero client `reader_allowed_source_uris`). User, folder, and workspace text blocks are delimited and sanitized against `[LAYER_*]` / `[CONSTITUTIONAL_*]` tag injection.
  5. **Governed Tool Chain, Forbidden Direct SI Writes & MCP `assistant.ask` (`D1`, `D6`, `D7`):** Speed 2/3 tool invocations flow exclusively through `GovernedAssistantToolRouter`: `PermissionBroker` -> `V5` / deterministic human-anchor guard -> sandboxed executor (`asyncio.wait_for`) -> secret scrubber -> append-only `audit_ledger` (`ASSISTANT_TOOL_INVOKED` / `ASSISTANT_TOOL_DENIED`) + `domain_events_outbox`. `ConnectorReflexiveWriteGateAdapter` is forbidden in the `ASSISTANT` profile. Any requested SI mutation or workflow launch emits `approval_required` and transitions via `CONTINUE_IN_PROCESS` onto durable DBOS + PostgreSQL 18 execution (`AD-2`) halting at `WAITING_FOR_HUMAN_ANCHOR` (`AD-3`, `HTTP 422 ERR_HUMAN_ANCHOR_REQUIRED`). MCP tool `assistant.ask` (`POST /api/v1/mcp/spaces/<ws>/invoke`) routes through `AssistantTurnEngine` in synchronous Speed 1 read-only governed mode under the 7 MCP hardware locks, `QuotaGuard`, `ScopeAccessGuard`, server-side `READ_SOURCE` / `CONFIDENTIAL_RESTRICTED`, `AssistantPromptBuilder`, and `CitationGuard` (zero SI writes, zero recursive tool loop).
  6. **Adapter Boundary (`LlmStreamingPort`, 3 Text Adapters + 2 Tool Dialects) (`D5`, `R7`):** `LlmStreamingPort` (`packages/orcia-core/src/orcia_core/ports/`, zero vendor SDK imports per `AD-19`) preserves all 3 `httpx` text/reasoning streaming adapters (`openai_compatible`, `anthropic`, `gemini_native` `CAP-076`) with strict `thinking`/`content` separation, while native `tool_calls` streaming/non-streaming parsing and re-injection is scoped to **2 dialects** (`openai_compatible` and `anthropic` per `AD-24` Rule 8; `ACTION_ITEM-26.4`).
  7. **Zero RAM Business State, Measure-First Prompt Assembly & Direct Cutover (`D4`, `D8`, `R4`, `R5`, `R6`):** Conversational turns persist `user` and `assistant` messages in `assistant_thread_messages` (detailed tool execution traces stay isolated in `reflexive_execution_sessions` keyed by `turn_id` and are never re-injected as `role: "tool"`); user feedback persists in `assistant_turn_feedback` (`UNIQUE (turn_id, user_id)` upsert); phantom citations stripped by `CitationGuard` are logged to append-only `audit_ledger` (`ASSISTANT_PHANTOM_CITATION_PURGED`) with **no** `assistant_citation_drafts` table (`R5`). **No** assembled-prompt Redis cache or Outbox prompt-cache invalidation consumer is implemented upfront (`R6`, explicitly recording `FR-33` / Story `10.2` deferral in `ACTION_ITEM-26.3` unless measured SQL prompt-assembly `p95 > 50 ms`). Backend, `apps/web`, and E2E specs cut over atomically in `26.7` to `/api/v1/assistant/turns*` with **no** `/three-speed/*` strangler facade (`ACTION_ITEM-26.2`, `R4`), deleting obsolete routes directly as their replacements land.
